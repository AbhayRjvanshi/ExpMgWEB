\# SOURCE QUALITY HEURISTICS



\## Purpose



This document defines how design research sources should be evaluated during internet-based design exploration.



The goal is to prevent:



\* inaccessible design influence,

\* trend-heavy visual bias,

\* copied template ecosystems,

\* low-quality inspiration spam,

\* and unrealistic production patterns.



\---



\# Preferred Sources



Preferred sources are:



\* official design systems,

\* production-grade applications,

\* accessibility-focused systems,

\* enterprise SaaS products,

\* trusted UX research,

\* and large-scale real-world interfaces.



These sources should strongly influence:



\* layout systems,

\* accessibility decisions,

\* typography hierarchy,

\* spacing systems,

\* interaction design,

\* and component architecture.



\---



\# Low Priority Sources



Low priority sources include:



\* visual-only inspiration boards,

\* trend showcase platforms,

\* concept-heavy Dribbble designs,

\* experimental portfolio interfaces,

\* and AI-generated UI galleries.



These may be used only as:



\* secondary inspiration,

\* micro-interaction references,

\* or aesthetic exploration.



They must NEVER dominate:



\* usability decisions,

\* accessibility decisions,

\* or layout architecture.



\---



\# Blocked Sources



Blocked sources include:



\* stolen template repositories,

\* spam template farms,

\* malware-heavy websites,

\* fake clone galleries,

\* and mass-generated UI dumps.



These sources must be ignored completely.



\---



\# Trend vs Usability Principle



Usability takes priority over visual trendiness.



The system must:



\* prefer readability over visual complexity,

\* prefer accessibility over aesthetics,

\* prefer scalability over visual novelty,

\* and prefer production realism over showcase appearance.



\---



\# Anti-Copycat Detection



The system should detect:



\* repeated template ecosystems,

\* duplicated component structures,

\* mass-cloned dashboard layouts,

\* and low-originality UI systems.



Detected copycat systems should receive reduced credibility weighting.



\---



\# Accessibility Rules



The system should penalize:



\* low contrast designs,

\* poor typography hierarchy,

\* inaccessible spacing,

\* mobile-hostile layouts,

\* and interaction patterns that reduce usability.



The system should prefer:



\* WCAG-aligned systems,

\* readable typography,

\* scalable spacing systems,

\* and production-proven accessibility patterns.
